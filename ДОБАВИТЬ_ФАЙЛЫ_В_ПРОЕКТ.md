# Инструкция по добавлению файлов в проект

После создания всех файлов через Kiro, необходимо добавить их в проект Visual Studio.

## Способ 1: Автоматическое добавление

1. В **Solution Explorer** нажмите на кнопку **Show All Files** (вверху панели)
2. Все новые файлы появятся с серым значком
3. Выберите папки **Pages**, **Resources** (правой кнопкой)
4. Выберите **Include In Project**

## Способ 2: Ручное добавление

### Добавьте следующие файлы XAML:

#### Pages:
- `Pages/SignInPage.xaml`
- `Pages/Guest/GuestPage.xaml`
- `Pages/Admin/AdminPage.xaml`
- `Pages/Admin/Tabs/ProductsTab.xaml`
- `Pages/Admin/Tabs/OrdersTab.xaml`
- `Pages/Manager/ManagerPage.xaml`
- `Pages/Client/ClientPage.xaml`

#### Resources:
- `Resources/Styles.xaml`
- `Resources/Images/*.jpg` (установить **Build Action = Resource**)
- `Resources/Images/*.png` (установить **Build Action = Resource**)

### Для каждого XAML файла:

1. Правой кнопкой на папку → **Add → Existing Item**
2. Выберите файл `.xaml`
3. Visual Studio автоматически добавит файл `.xaml.cs`
4. Если не добавился, повторите для `.xaml.cs` файла

## Способ 3: Редактирование .csproj вручную

Откройте файл `Demovar5.csproj` в текстовом редакторе и добавьте в секцию `<ItemGroup>`:

```xml
<ItemGroup>
  <!-- Pages XAML -->
  <Page Include="Pages\SignInPage.xaml">
    <SubType>Designer</SubType>
    <Generator>MSBuild:Compile</Generator>
  </Page>
  <Page Include="Pages\Guest\GuestPage.xaml">
    <SubType>Designer</SubType>
    <Generator>MSBuild:Compile</Generator>
  </Page>
  <Page Include="Pages\Admin\AdminPage.xaml">
    <SubType>Designer</SubType>
    <Generator>MSBuild:Compile</Generator>
  </Page>
  <Page Include="Pages\Admin\Tabs\ProductsTab.xaml">
    <SubType>Designer</SubType>
    <Generator>MSBuild:Compile</Generator>
  </Page>
  <Page Include="Pages\Admin\Tabs\OrdersTab.xaml">
    <SubType>Designer</SubType>
    <Generator>MSBuild:Compile</Generator>
  </Page>
  <Page Include="Pages\Manager\ManagerPage.xaml">
    <SubType>Designer</SubType>
    <Generator>MSBuild:Compile</Generator>
  </Page>
  <Page Include="Pages\Client\ClientPage.xaml">
    <SubType>Designer</SubType>
    <Generator>MSBuild:Compile</Generator>
  </Page>
  <Page Include="Resources\Styles.xaml">
    <SubType>Designer</SubType>
    <Generator>MSBuild:Compile</Generator>
  </Page>
</ItemGroup>

<ItemGroup>
  <!-- Code-behind files -->
  <Compile Include="Pages\SignInPage.xaml.cs">
    <DependentUpon>SignInPage.xaml</DependentUpon>
  </Compile>
  <Compile Include="Pages\Guest\GuestPage.xaml.cs">
    <DependentUpon>GuestPage.xaml</DependentUpon>
  </Compile>
  <Compile Include="Pages\Admin\AdminPage.xaml.cs">
    <DependentUpon>AdminPage.xaml</DependentUpon>
  </Compile>
  <Compile Include="Pages\Admin\Tabs\ProductsTab.xaml.cs">
    <DependentUpon>ProductsTab.xaml</DependentUpon>
  </Compile>
  <Compile Include="Pages\Admin\Tabs\OrdersTab.xaml.cs">
    <DependentUpon>OrdersTab.xaml</DependentUpon>
  </Compile>
  <Compile Include="Pages\Manager\ManagerPage.xaml.cs">
    <DependentUpon>ManagerPage.xaml</DependentUpon>
  </Compile>
  <Compile Include="Pages\Client\ClientPage.xaml.cs">
    <DependentUpon>ClientPage.xaml</DependentUpon>
  </Compile>
</ItemGroup>

<ItemGroup>
  <!-- Images as Resources -->
  <Resource Include="Resources\Images\*.jpg" />
  <Resource Include="Resources\Images\*.png" />
  <Resource Include="Resources\Images\*.ico" />
</ItemGroup>
```

## После добавления файлов:

1. Закройте и снова откройте Visual Studio
2. Выполните **Build → Rebuild Solution**
3. Проверьте, что нет ошибок компиляции
4. Запустите приложение (F5)
