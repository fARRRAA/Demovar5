## 📝 Шаг 1: Добавьте файлы в проект Visual Studio

### Способ 1: Автоматический (рекомендуется)

1. Откройте проект в Visual Studio
2. В **Solution Explorer** нажмите кнопку **"Show All Files"** (иконка с листочками)
3. Вы увидите новые папки с серыми иконками:
   - `Pages/`
   - `WindowDialogs/`
   - `Resources/`
4. Правой кнопкой на эти папки → **"Include In Project"**
5. Visual Studio автоматически добавит все файлы

## 🐛 Возможные ошибки и решения

### Ошибка: "The type or namespace name 'HandyControl' could not be found"
**Решение:** Установите HandyControl через NuGet

### Ошибка: "Cannot open database MebelOrgDB"
**Решение:** Выполните SQL-скрипт `CreateDatabase.sql`

### Ошибка: "Could not load file or assembly 'EntityFramework'"
**Решение:** В Package Manager Console:
```powershell
Update-Package EntityFramework -Reinstall
```

### Изображения не отображаются
**Решение:**
1. Убедитесь, что изображения скопированы в `Resources/Images/`
2. В Solution Explorer → выберите изображения → Properties → Build Action = **Resource**

### Ошибка компиляции в AddEditProductWindow
**Решение:** Добавьте в начало файла:
```csharp
using Microsoft.Win32; // Для OpenFileDialog
```
