### ✅ Модуль 2: Разработка приложения и алгоритма (выполнено 90%)

#### Создано WPF-приложение с использованием:
- **HandyControl** - современная библиотека UI компонентов
- **Entity Framework** - для работы с БД
- **Структура Pages/WindowDialogs** (без MVVM, как требовалось)

#### Реализованные страницы:

1. **SignInPage** - Страница авторизации
   - Валидация логина/пароля
   - Переход к соответствующей роли
   - Вход как гость

2. **GuestPage** - Просмотр товаров для гостей
   - Отображение всех товаров
   - Без фильтрации, сортировки, поиска
   - Карточки товаров с фото, описанием, ценой

3. **ClientPage** - Личный кабинет клиента
   - Просмотр товаров (без фильтрации)
   - Отображение ФИО в шапке
   - Кнопка выхода

4. **ManagerPage** - Панель менеджера
   - Просмотр товаров с фильтрацией, сортировкой, поиском
   - Просмотр заказов
   - Боковая навигация с вкладками

5. **AdminPage** - Панель администратора
   - Полный доступ ко всем функциям
   - Управление товарами (просмотр, добавление, редактирование, удаление)
   - Управление заказами (просмотр, добавление, редактирование, удаление)
   - Боковая навигация с вкладками

#### Реализованные вкладки:

1. **ProductsTab** (для Администратора):
   - ✅ Поиск по всем текстовым полям (название, артикул, описание и т.д.)
   - ✅ Фильтрация по скидке (0-10,99%, 11-14,99%, 15% и более)
   - ✅ Сортировка (по цене↑↓, по остатку↑↓)
   - ✅ Отображение в реальном времени
   - ✅ Удаление товаров (с проверкой наличия в заказах)
   - 🔄 Добавление товаров (в разработке)
   - 🔄 Редактирование товаров (в разработке)

2. **OrdersTab** (для Администратора):
   - ✅ Просмотр списка заказов
   - ✅ Удаление заказов
   - 🔄 Добавление заказов (в разработке)
   - 🔄 Редактирование заказов (в разработке)
   - 🔄 Просмотр состава заказа (в разработке)

#### Стилизация согласно требованиям:

✅ **Шрифт**: Calibri
✅ **Цвета**:
  - Основной фон: #FFFFFF (белый)
  - Дополнительный фон: #00FFFF (голубой)
  - Акцентный цвет: #0000FF (синий)
  - Высокая скидка (>15%): #008080 (бирюзовый)

✅ **Логика отображения товаров**:
  - Скидка > 15% → фон бирюзовый (#008080)
  - Есть скидка → основная цена перечёркнута красным, рядом итоговая
  - Нет на складе → серый фон
  - Заглушка для товаров без фото (picture.png)
