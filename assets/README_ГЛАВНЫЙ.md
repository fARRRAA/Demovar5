## 📋 Описание проекта

Информационная система для управления мебельным магазином "МебельОрг" с поддержкой различных ролей пользователей, управлением товарами и заказами.

### Основной функционал:
- ✅ Авторизация пользователей с разграничением прав доступа
- ✅ Просмотр каталога товаров с фильтрацией, сортировкой и поиском
- ✅ Управление товарами (добавление, редактирование, удаление)
- ✅ Управление заказами (просмотр, добавление, редактирование, удаление)
- ✅ Отображение скидок и остатков на складе

---

## 🏗️ Архитектура

### Технологический стек:
- **Frontend**: WPF (.NET Framework 4.7.2)
- **UI Library**: HandyControl 3.4.0
- **Backend**: C# Code-behind (без MVVM)
- **Database**: Microsoft SQL Server
- **ORM**: Entity Framework 5.0

### Структура БД (3НФ):
- **Roles** - Роли пользователей
- **Users** - Пользователи
- **Products** - Товары
- **Categories** - Категории товаров
- **Manufacturers** - Производители
- **Suppliers** - Поставщики
- **Units** - Единицы измерения
- **Orders** - Заказы
- **OrderProducts** - Состав заказа
- **PickupPoints** - Пункты выдачи

## 🎨 Дизайн (согласно требованиям)

### Цветовая схема:
- **Основной фон**: `#FFFFFF` (белый)
- **Дополнительный фон**: `#00FFFF` (голубой)
- **Акцентный цвет**: `#0000FF` (синий)
- **Высокая скидка (>15%)**: `#008080` (бирюзовый)
- **Шрифт**: Calibri

### Особенности отображения товаров:
1. **Скидка > 15%** → Фон карточки бирюзовый
2. **Товар со скидкой** → Основная цена перечёркнута, рядом цена со скидкой
3. **Нет на складе** → Серый фон

## 👥 Роли пользователей

### 🚶 Гость (без авторизации):
- Просмотр каталога товаров (без фильтрации, сортировки, поиска)

### 👤 Авторизированный клиент:
- Просмотр каталога товаров (без фильтрации, сортировки, поиска)
- Личный кабинет

### 📊 Менеджер:
- Просмотр товаров (с фильтрацией, сортировкой, поиском)
- Просмотр заказов

### 👨‍💼 Администратор:
- Полный доступ ко всем функциям
- Управление товарами (CRUD)
- Управление заказами (CRUD)

## 🚀 Быстрый старт

### 1. Установите HandyControl:
```powershell
Install-Package HandyControl -Version 3.4.0
```

### 2. Создайте базу данных:
Выполните скрипт **`CreateDatabase.sql`** в SQL Server Management Studio

### 3. Скопируйте изображения:
Из `module1/import/` в `Demovar5/Demovar5/Resources/Images/`

### 4. Запустите приложение:
Нажмите **F5** в Visual Studio

**Подробные инструкции**: см. файл [`ИНСТРУКЦИЯ_ПО_ЗАПУСКУ.md`](ИНСТРУКЦИЯ_ПО_ЗАПУСКУ.md)
