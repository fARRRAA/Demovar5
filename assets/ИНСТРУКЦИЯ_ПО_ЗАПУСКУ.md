# 🚀 Инструкция по запуску приложения

## Шаг 1: Установка HandyControl

### Способ 1: Package Manager Console
1. В Visual Studio откройте **Tools → NuGet Package Manager → Package Manager Console**
2. Выполните команду:
```powershell
Install-Package HandyControl -Version 3.4.0
```

### Способ 2: NuGet Package Manager (UI)
1. Правой кнопкой на проект **Demovar5** → **Manage NuGet Packages**
2. Перейдите на вкладку **Browse**
3. Найдите **HandyControl**
4. Выберите версию **3.4.0** или выше
5. Нажмите **Install**

---

## Шаг 2: Создание базы данных

1. Откройте **SQL Server Management Studio** (SSMS)
2. Подключитесь к вашему экземпляру SQL Server
3. Откройте файл **`CreateDatabase.sql`** из корня проекта
4. Выполните скрипт (F5)
5. Убедитесь, что база данных **MebelOrgDB** создана

**Проверка:**
```sql
USE MebelOrgDB;
SELECT COUNT(*) FROM Products;  -- Должно быть 10 товаров
SELECT COUNT(*) FROM Users;     -- Должно быть 10 пользователей
SELECT COUNT(*) FROM Orders;    -- Должно быть 10 заказов
```

---

## Шаг 3: Настройка строки подключения

Откройте файл **`Demovar5/Demovar5/App.config`** и проверьте строку подключения:

```xml
<connectionStrings>
  <add name="demovar5Entities" 
       connectionString="metadata=res://*/Model1.csdl|res://*/Model1.ssdl|res://*/Model1.msl;
       provider=System.Data.SqlClient;
       provider connection string=&quot;
       data source=(localdb)\MSSQLLocalDB;
       initial catalog=MebelOrgDB;
       integrated security=True;
       MultipleActiveResultSets=True;
       App=EntityFramework&quot;" 
       providerName="System.Data.EntityClient" />
</connectionStrings>
```

### Если используете другой SQL Server:

Замените `data source=(localdb)\MSSQLLocalDB` на:
- **Локальный SQL Server**: `data source=localhost` или `data source=.`
- **Named Instance**: `data source=.\SQLEXPRESS`
- **Удалённый сервер**: `data source=SERVER_NAME\INSTANCE_NAME`

## Шаг 4: Копирование изображений

Скопируйте изображения товаров из **`module1/import/`** в **`Demovar5/Demovar5/Resources/Images/`**:

### Файлы для копирования:
- `1.jpg` - `10.jpg` (фото товаров)
- `icon.png` (логотип компании)
- `icon.ico` (иконка приложения)
- `picture.png` (заглушка для товаров без фото)

### PowerShell команда:
```powershell
Copy-Item "module1/import/*.jpg" "Demovar5/Demovar5/Resources/Images/"
Copy-Item "module1/import/*.JPG" "Demovar5/Demovar5/Resources/Images/"
Copy-Item "module1/import/*.png" "Demovar5/Demovar5/Resources/Images/"
Copy-Item "module1/import/*.ico" "Demovar5/Demovar5/Resources/Images/"
```

**Важно**: В Visual Studio убедитесь, что у файлов установлен **Build Action = Resource**

## ⚠️ Возможные проблемы и решения

### 1. Ошибка: "Cannot open database MebelOrgDB"
**Решение**: 
- Убедитесь, что SQL Server запущен
- Проверьте строку подключения в `App.config`
- Выполните скрипт `CreateDatabase.sql` повторно

### 2. Ошибка: "Could not load file or assembly HandyControl"
**Решение**: 
- Переустановите HandyControl через NuGet
- Проверьте, что пакет установлен в проект **Demovar5**, а не в решение

### 3. Изображения не отображаются
**Решение**: 
- Убедитесь, что изображения скопированы в `Resources/Images/`
- В Solution Explorer выберите изображения → Properties → Build Action = **Resource**

### 4. Ошибка компиляции: "The type or namespace name 'HandyControl' could not be found"
**Решение**: 
- Очистите решение: **Build → Clean Solution**
- Пересоберите: **Build → Rebuild Solution**

### 5. Entity Framework не находит базу данных
**Решение**: 
- Откройте **Server Explorer** в Visual Studio
- Добавьте подключение к вашему SQL Server
- Проверьте, что база **MebelOrgDB** существует
