### Установка и запуск

#### 1. Установка HandyControl

Откройте **Package Manager Console** в Visual Studio и выполните:

\`\`\`powershell
Install-Package HandyControl -Version 3.4.0
\`\`\`

Или через **NuGet Package Manager**:
1. Правой кнопкой на проект → Manage NuGet Packages
2. Найдите "HandyControl"
3. Установите версию 3.4.0 или выше

#### 2. Настройка базы данных

1. Откройте SQL Server Management Studio
2. Выполните скрипт `CreateDatabase.sql` из корневой папки проекта
3. Это создаст базу данных **MebelOrgDB** со всеми таблицами и тестовыми данными

#### 3. Проверка строки подключения

Откройте файл `App.config` и убедитесь, что строка подключения правильная:

\`\`\`xml
<connectionStrings>
  <add name="demovar5Entities" 
       connectionString="metadata=res://*/Model1.csdl|res://*/Model1.ssdl|res://*/Model1.msl;provider=System.Data.SqlClient;provider connection string=&quot;data source=(localdb)\\MSSQLLocalDB;initial catalog=MebelOrgDB;integrated security=True;MultipleActiveResultSets=True;App=EntityFramework&quot;" 
       providerName="System.Data.EntityClient" />
</connectionStrings>
\`\`\`

**Если используете другой SQL Server**, измените `data source` на ваш экземпляр SQL Server.

#### 4. Копирование изображений

Изображения товаров должны находиться в папке:
\`\`\`
Demovar5/Demovar5/Resources/Images/
\`\`\`

Скопируйте файлы:
- 1.jpg - 10.jpg (фото товаров)
- icon.png (логотип)
- picture.png (заглушка для товаров без фото)

Из папки `module1/import/` в папку `Resources/Images/`

#### 5. Запуск приложения

1. Нажмите F5 или кнопку "Start" в Visual Studio
2. Приложение откроется на странице авторизации

### Особенности отображения товаров

Согласно требованиям демо-экзамена:

1. **Скидка > 15%** → Фон карточки: `#008080` (бирюзовый)
2. **Товар со скидкой** → Основная цена перечёркнута красным, рядом итоговая цена
3. **Товар отсутствует на складе** → Строка выделяется серым цветом

### Цветовая схема (согласно требованиям)

- **Основной фон**: `#FFFFFF` (белый)
- **Дополнительный фон**: `#00FFFF` (голубой)
- **Акцентный цвет**: `#0000FF` (синий)
- **Высокая скидка**: `#008080` (бирюзовый)
- **Шрифт**: Calibri

### Возможные проблемы и решения

#### Ошибка подключения к БД:
- Убедитесь, что SQL Server запущен
- Проверьте строку подключения в `App.config`
- Убедитесь, что база данных создана и заполнена данными

#### Не отображаются изображения:
- Убедитесь, что файлы скопированы в `Resources/Images/`
- В проекте файлы должны иметь **Build Action = Resource**

#### HandyControl не работает:
- Убедитесь, что пакет установлен через NuGet
- Проверьте, что в `App.xaml` добавлены ресурсы HandyControl
